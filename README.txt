Татьяна Шелест — новая версия сайта

Архив shelest-website.zip содержит готовую статическую страницу: index.html, style.css, app.js, content.json и папку assets с 64 изображениями исходного сайта.
Для размещения загрузите содержимое архива в корневую папку сайта или импортируйте код на выбранный хостинг.

Сохранены тексты, пять форматов мероприятий, услуги, семь проектов с бюджетами и ссылками на Яндекс Диск, галереи, отзывы, клиенты, контакты и социальные сети.
Описания форматов и дополнительные фотогалереи раскрываются по нажатию. Фотографии открываются в увеличенном просмотре; доступны стрелки, клавиши ← → и Escape.

Форма подготавливает письмо в почтовой программе пользователя. Автоматическая доставка заявок в Tilda не подключена. Для перехода на основной домен необходимо подключить существующий обработчик формы или сервис отправки. Телефон, email и мессенджеры работают по исходным ссылкам.

Проверено: ширина 1440 и 390 px, отсутствие горизонтального переполнения, работа мобильного меню, описаний и галереи; ошибок JavaScript и битых изображений не обнаружено. Тексты и ссылки сверены с HTML исходного сайта.
Основной сайт tanyashelest.ru в рамках этой работы не менялся.
