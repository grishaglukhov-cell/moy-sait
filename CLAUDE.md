# Сайт-визитка Глухов Григорий — таргетолог

Одностраничный сайт специалиста по платной рекламе (ВКонтакте, Яндекс.Директ, Авито).

## Стек

- **Чистый HTML/CSS/JS** — ноль фреймворков, ноль сборщиков, ноль npm
- **Один файл** — весь код в `index.html` (HTML + `<style>` + `<script>`)
- **Шрифты** — Google Fonts, три семейства:
  - `Bricolage Grotesque` — заголовки, крупный display-текст
  - `Manrope` — основной текст тела
  - `JetBrains Mono` — лейблы, бейджи, технические подписи
- **Фото** — `assets/grigory.png` (профессиональный портрет)
- **Хостинг** — статика, GitHub: `grishaglukhov-cell/moy-sait`

## Интерактив (vanilla JS)

- **Модальное окно** — `data-open-modal` на любом элементе открывает лид-форму; Escape и клик по оверлею закрывают
- **FAQ-аккордеон** — `.faq-item.is-open` через `classList.toggle`
- **Фильтр кейсов** — `data-niche` на карточках, `data-f` на чипах
- **Калькулятор** — мультивыбор каналов + слайдер бюджета + скидки за срок
- **Bottom-форма** — `submitBottomForm()` скрывает форму, показывает success-блок

## Правила — что нельзя делать

### Архитектура
- **Не добавлять фреймворки** (React, Vue, Alpine и др.) — сайт намеренно без зависимостей
- **Не дробить на файлы** — HTML, CSS и JS живут в одном `index.html`
- **Не подключать сборщики** (Vite, Webpack и т.п.) — деплой = просто открыть файл

### Дизайн
- **Не менять тёмную тему на светлую** — dark mode является частью визуальной идентичности
- **Не менять акцентный цвет** `#b8e34a` — он согласован с брендом
- **Не добавлять новые шрифты** — использовать только Bricolage Grotesque / Manrope / JetBrains Mono
- **Не использовать inline-стили для layout** — только CSS-классы и переменные
- **Не ставить тяжёлые анимации** — только `transition: .2s` для hover-эффектов

### UX
- **Не использовать `alert()`** — все ответы на действия пользователя через success-состояние в UI
- **Не убирать фиксированную corner-кнопку** — это основной CTA на мобильных
- **Не убирать auto-open модалки** — она срабатывает 1 раз за сессию через 35 с

### Контент
- **Не менять контактные данные** без согласования — телефон, Telegram, VK реальные
- **Не удалять секцию калькулятора** — ключевой интерактивный элемент для вовлечения

## Частые задачи

**Добавить кейс:**
Скопировать `<article class="case ...">` в `#cases .cases-grid`, задать нужный `data-niche` (finance / b2b / local / hr).

**Добавить вопрос в FAQ:**
Скопировать `<div class="faq-item">` в `#faq-list`.

**Подключить приём заявок на почту:**
Заменить `onsubmit` обеих форм на Web3Forms: добавить `<input type="hidden" name="access_key" value="ВАШ_КЛЮЧ">` и `action="https://api.web3forms.com/submit"`.

**Обновить цены в калькуляторе:**
Найти `data-price="30000"` / `data-price="40000"` / `data-price="35000"` в `#calc-channels` и поменять значения.
