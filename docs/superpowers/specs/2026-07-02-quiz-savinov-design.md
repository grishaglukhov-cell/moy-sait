# Лендинг-квиз для хирурга Савинова — дизайн

## Контекст

Новый, независимый проект внутри текущего репозитория. Не связан с существующим сайтом-визиткой таргетолога (`index.html` в корне) и не подчиняется правилам его `CLAUDE.md` (тёмная тема, акцент `#b8e34a`, шрифты Bricolage/Manrope/JetBrains Mono) — у этого лендинга своя, полностью независимая визуальная идентичность.

## Цель

Лендинг с квизом для пластического хирурга Александра Савинова (клиника «Основа Силуета», Москва). Квиз ведёт пользователя от выбора интересующей процедуры к персональному результату и форме записи на консультацию.

## Данные клиента (реальные)

```
Хирург:  Савинов Александр
Клиника: «Основа Силуета», Москва
Услуги:  Блефаропластика · Тотальное омоложение · Маммопластика
Телефон: +7 (905) 428-46-26
```

## Стек

- Чистый HTML/CSS/JS, ноль фреймворков и сборщиков — тот же принцип, что и в основном сайте
- Один файл: весь код в `quiz-savinov/index.html` (HTML + `<style>` + `<script>`)
- Собственная папка `quiz-savinov/` в корне репозитория, с при необходимости отдельным `quiz-savinov/assets/`
- Никак не изменяет существующий `index.html` таргетолога

## Визуальный стиль

### Палитра — светлая, без цветного акцента

```css
--bg: #faf8f5        /* тёплый почти-белый фон */
--bg-2: #f2efe9      /* фон секций/карточек */
--card: #ffffff      /* карточки квиза */
--line: rgba(20,20,18,0.08)     /* граница */
--line-2: rgba(20,20,18,0.16)   /* граница акцентная */
--ink: #1c1b19       /* основной текст */
--ink-2: #55524c     /* вторичный текст */
--muted: #8c887f     /* приглушённый текст */
--radius: 24px
--radius-lg: 32px
```

Акцент — не цвет, а контраст: тёмные заливки/обводки (`--ink`) на светлом фоне. Прогресс-бар, выбранные ответы, кнопки — тёмные на светлом. Один тёплый бежевый оттенок (`--bg-2`) отличает секции друг от друга. Никаких ярких/цветных акцентных цветов.

Только `transition: .2s` на hover/переходах между шагами квиза — без тяжёлых анимаций, в духе правил основного сайта.

## Структура страницы

```
Экран-обложка   — имя хирурга, клиника, город, короткий питч, CTA «Пройти тест»
Квиз (5 шагов)  — прогресс-бар/точки сверху
  Шаг 1/5       — выбор процедуры (общий для всех веток)
  Шаг 2-4/5     — вопросы, ветвящиеся по выбору шага 1 (см. ниже)
  Шаг 5/5       — фильтр по противопоказаниям (общий, не блокирует прохождение)
Экран результата — персональный вывод + 2-3 буллета почему + факт о докторе
Форма контактов  — имя + телефон, success-состояние в UI
```

### Ветвление квиза (вариант «по процедуре»)

Шаг 1 — пользователь выбирает одну из трёх процедур карточками-иконками:
- Блефаропластика
- Тотальное омоложение
- Маммопластика

Шаги 2–4 адаптируются под выбор:

**Блефаропластика:**
1. Зона: верхние веки / нижние веки / обе
2. Что беспокоит: нависшее веко / мешки под глазами / асимметрия
3. Желаемые сроки операции

**Тотальное омоложение:**
1. Приоритетные зоны: лицо / шея / овал лица
2. Желаемый эффект (свободный выбор из вариантов: убрать морщины / подтянуть контур / освежить в целом)
3. Желаемые сроки операции

**Маммопластика:**
1. Желаемый результат: увеличение / подтяжка / уменьшение
2. Текущий размер (диапазон)
3. Желаемые сроки операции

Шаг 5 (общий для всех веток) — чекбоксы-фильтр по противопоказаниям: курение, хронические заболевания, ранее проводились операции. Это не блокирует прохождение квиза — используется только для формирования персонального результата и информирования хирурга.

### Экран результата

На основе выбора шага 1 и уточняющих ответов показывается персональный вывод в формате «Вам подходит [процедура] [конкретика из уточнений]» + 2-3 буллета почему именно этот вариант подходит + короткий факт/фраза о докторе Савинове для укрепления доверия перед тем, как запросить контакты.

### Форма контактов

Поля: имя, телефон. Кнопка отправки. По правилам проекта — без `alert()`: успешная отправка переключает форму в success-состояние прямо в UI. Отправка на сервер/Telegram-бот **не реализуется в этой итерации** — это заглушка (`console.log` данных формы + переключение в success-состояние). Интеграция с приёмом заявок будет добавлена отдельной задачей позже.

## Вне рамок этой итерации

- Отправка заявок в Telegram или на почту (заглушка, добавляется позже)
- Фото хирурга / клиники (можно использовать плейсхолдер или добавить позже в `quiz-savinov/assets/`)
- Мобильная и десктопная адаптация — предполагается стандартный адаптивный подход (как в основном сайте), без отдельных уточнений в этой спеке
